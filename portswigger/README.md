## Study order

1. Essential skills — material only (its 2 labs require Burp Pro)
2. SQL injection → Access control → Authentication → XSS
3. CSRF, CORS, Clickjacking
4. Information disclosure, Business logic, Path traversal, Command injection
5. File upload, SSRF, GraphQL, API testing

Deferred (stage 2, weeks 9+): HTTP request smuggling, insecure deserialization,
prototype pollution, web cache poisoning/deception, race conditions, JWT,
OAuth, Web LLM attacks.
